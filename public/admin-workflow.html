📚 How Workflow System Works

  1. Create Steps: Story progression is organized into chronological steps (e.g., "Episode 1", "Episode 2")
  2. Add Actions: Each step can have multiple actions (CLAIM, UNPACK, BLEND, DROP, MARKET_SCOUT)
  3. Set Conditions: Actions can have conditions that must be met (e.g., "Own templates X, Y, Z")
  4. Users Progress: Users complete actions in order, unlocking the next steps in the story
