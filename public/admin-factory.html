📚 Factory System Overview

How Factory Works:

  1. Configure craft recipes with ingredient requirements and results
  2. Users transfer ingredient assets to futuresrelic wallet
  3. Server verifies transfer, then mints result assets
  4. Safe transfer-first approach (assets held, can refund if mint fails)
