💡 How to Use Story Tabs

  1. Create Tabs: Create tabs for different segments (e.g., "Daily", "Weekly", "Main Story")
  2. Assign Actions to Tabs: Go to "Story Workflow" and edit actions to assign them to specific tabs
  3. Users See Tabs: Players will see tabs in the Story page and can click to filter actions
  4. Hide Main Tabs: Use Navigation Settings to hide "Claim Rewards" or "Unpack" if not needed
